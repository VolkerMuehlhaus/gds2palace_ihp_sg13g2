# XML stackup files for gds2palace workflow

Stackup files in this repository are for gds2palace, do not use them with gds2openEMS. There are some subtle differences (like MIM dielectric modelling) due to solver method.

---

The latest stackup files can be found in the [latest](../latest) folder. They make use of new XML file format features such as variables, see the [XML stackup format description](../../doc/XML_stackup_format/XML_stackup_format.md).

The legacy folder contains previous versions for compatibility only.  

**For new models, it is recommended to use the XML stackup files from the [latest](../latest) folder.**
